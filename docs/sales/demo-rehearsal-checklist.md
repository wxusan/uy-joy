# Demo Rehearsal Checklist

Run twice before a client meeting.

## Data

- [ ] `DEMO_DATABASE_CONFIRM=demo npm run demo:reset` completed.
- [ ] Demo DB is not a client production DB.
- [ ] 50 fake leads exist across all pipeline stages.
- [ ] 13 fake deals exist across reserved, contract preparation, payment active, sold, and cancelled.
- [ ] Units include at least 20 available, 6 reserved, and 6 sold examples.
- [ ] Documents include uploaded, approved, and rejected statuses.
- [ ] Reports show non-empty charts and useful totals.
- [ ] No real private names, phones, documents, or client data are present.

## Desktop Flow

- [ ] Public page loads with Mirabad Heights brand.
- [ ] CTA buttons work.
- [ ] Lead form creates a CRM lead.
- [ ] Telegram notification is available or backup screenshot/recording is ready.
- [ ] New CRM lead opens.
- [ ] Pipeline drag works.
- [ ] Lead/client profile shows a timeline.
- [ ] Deal profile opens.
- [ ] Reservation/payment/document examples are visible.
- [ ] Executive, marketing, inventory, finance, and agent reports load.

## Mobile Flow

- [ ] Public page first viewport has no overlap.
- [ ] Lead form works on mobile viewport.
- [ ] CRM pipeline is usable for read-only demo on mobile.
- [ ] Lead profile is readable on mobile.

## Backup Recording

Record a 3-5 minute local walkthrough before serious meetings:

1. public page and lead form
2. Telegram notification
3. CRM lead and pipeline
4. deal/payment/document profile
5. owner reports

Store the video outside the repo with the sales materials. Keep this checklist updated with the file location when the recording is made.
