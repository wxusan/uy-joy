## 0-2 Minutes: Positioning

Say:

> This is not just a CRM. It is your own branded digital sales office: public page, Telegram lead capture, CRM, apartment inventory, reservations, payment plans, documents, and owner reports.

## 2-6 Minutes: Public Page

- branded first viewport

## 6-8 Minutes: Telegram

Show the muted/private demo Telegram channel, or use the prepared screenshot/recording if internet is slow.

Value line:

> Telegram remains fast, but now it is connected to assignment, follow-up, inventory, payments, and reports.

## 8-15 Minutes: CRM

Show:

- lead inbox
- pipeline with realistic distribution
- client profile timeline
- assignment and tasks
- sales agent limited view if asked

Value line:

> Owners see process. Managers see who is acting. Agents see what to do next.

## 15-22 Minutes: Real-Estate Workflow

Show:

- open a unit from a lead/deal
- deal profile
- calculator and discount approval signal
- reserve a unit
- payment plan examples
- documents with approved/uploaded/rejected statuses

Value line:

> The CRM is connected to the thing being sold: exact apartments, exact prices, exact payment schedules.

## 22-28 Minutes: Reports

Show:

- executive report
- sales report
- marketing report
- inventory report
- finance report
- weekly digest preview

Value line:

> This is how the developer sees lead quality, agent performance, inventory movement, and expected payments without asking five people for spreadsheets.

## 28-30 Minutes: Offer

Recommend one package:

- Lead Capture Platform for small teams that only need public page + Telegram + lead inbox.
- Real Estate CRM for teams that already have inventory elsewhere.
- Full Digital Sales Office for developers who want public page, CRM, inventory, deals, payments, documents, and reports in one product.

Close:

> The first step is a pilot setup: domain, branded page, users, Telegram, first project inventory, and one week of team onboarding.

## What Not To Show

- raw environment variables
- migrations or database screens
- empty dashboards
- unfinished integration pages
- developer account unless discussing support/trust
- real client data or real personal documents
- pricing admin controls unless discussing package structure

## Failure Backup

- If Telegram fails: show the backup screenshot/recording and continue the CRM flow.
- If internet is slow: use local demo or screen recording.
- If client asks for a feature not built: place it in add-ons or roadmap.
- If client asks for a discount: discount setup, not monthly support.
